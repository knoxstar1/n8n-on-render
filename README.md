# n8n on Render

Deploys [n8n](https://n8n.io) to [Render](https://render.com) as a Node web service backed by Render Postgres, so workflows and credentials survive redeploys.

## Deploy

1. In Render, choose **New > Blueprint** and select this repository. Render reads `render.yaml` and creates:
   - `n8n`: a Node 24 web service running `npm start` (`n8n start`).
   - `n8n-db`: a Postgres database wired in through the `DB_POSTGRESDB_*` variables.
2. When prompted, fill in the `sync: false` variables:
   - `N8N_HOST`: your service hostname, e.g. `n8n-xxxx.onrender.com` (no scheme).
   - `WEBHOOK_URL`: the full public URL with a trailing slash, e.g. `https://n8n-xxxx.onrender.com/`.
3. After the first deploy, open the service URL and create the **owner account** right away. Until you do, anyone who finds the URL can claim it. n8n's user management replaces the old `N8N_BASIC_AUTH_*` variables, which n8n no longer supports.

## Environment variables

| Variable | Source | Purpose |
| --- | --- | --- |
| `N8N_ENCRYPTION_KEY` | generated by Render | Encrypts saved credentials. Back it up; if it is lost, saved credentials cannot be decrypted. |
| `N8N_PORT` / `PORT` | `render.yaml` | Port n8n listens on (`10000`, Render's default). |
| `N8N_HOST`, `N8N_PROTOCOL`, `WEBHOOK_URL` | dashboard / `render.yaml` | Public URL used for the editor and webhooks. |
| `DB_TYPE`, `DB_POSTGRESDB_*` | Render database | Postgres connection. |
| `GENERIC_TIMEZONE` | `render.yaml` | Default timezone for schedules. |

See `.env.example` for local development. Copy it to `.env`, which is git-ignored, and never commit real values.

## Local run

```bash
npm install
cp .env.example .env   # edit values, then export them or use a tool such as direnv
npm start
```

## Upgrading n8n

`n8n` is pinned to an exact version in `package.json`. Dependabot opens weekly PRs for updates. Read the n8n release notes before you merge one.

## Security

- This repo previously contained injected malware: an obfuscated `api.js`, a fake font file, and a `.vscode/tasks.json` that ran it automatically. It has been removed. If you cloned or opened an older copy, delete that clone and re-clone.
- Never commit `.env` files, API keys, or n8n credential exports.
- `.vscode/` is git-ignored so that editor tasks cannot be smuggled into the repo again. Be wary of any PR that adds editor tasks, `postinstall` scripts, or changes to the `start` script.
- Enable 2FA on GitHub and Render, and rotate `N8N_ENCRYPTION_KEY` and the database credentials if you think they were exposed.
